## Problem

You are given a **0-indexed** binary string `s` having an even length.

A string is **beautiful** if it's possible to partition it into one or more substrings such that:

- Each substring has an **even length**.
- Each substring contains **only** `1`'s or **only** `0`'s.

You can change any character in `s` to `0` or `1`.

Return _the **minimum** number of changes required to make the string_ `s` _beautiful_

---
# Example 1

**Input:** `s = "1001"`

**Output:** 2

**Explanation:**

```python
We change s[1] to 1 and s[3] to 0 to get string "1100".
It can be seen that the string "1100" is beautiful because we can partition it into "11|00".
It can be proven that 2 is the minimum number of changes needed to make the string beautiful.
```

---
# Solution

>[!important] Intuition
>- Check if already beautiful if so skip
>- Switching from 0 to 1 or 1 to 0 always happens at an even index due to problem being even
>- So a switch can never be odd which is why we increment by 2

**Analogy**:
Suppose every price is an even number of cents. With 2-cent coins you can pay any price exactly. With 4-cent coins you can’t pay 6 cents without overpaying. The overpaying is like the extra changes you’d make by checking in 4s.

```python
class Solution:
    def minChanges(self, s: str) -> int:
        res = 0
        for i in range(0,len(s),2):
            if s[i] != s[i+1]:
                res += int (s[i])+ int(s[i+1])
        return res
```
