## Problem

Given an integer array `nums`, return _the length of the longest **strictly increasing subsequence**.

---
# Example 1

**Input:** `nums = [10,9,2,5,3,7,101,18]`

**Output:** 4

**Explanation:** `The longest increasing subsequence is [2,3,7,101], therefore the length is 4.`


---
# Solution

>[!important] Intuition
> - Recursion is kind of like decision tree we try each index, excluding the one we were just at. 
> - For every element look at everything to the right (reverse remember) and as if a bigger number comes after me, how long a chain can i build by jumping to it
> - We go in reverse so that whenever we compute `dp[i]`, the answers for every index to the right are already finished — then, for `i` itself, we check each of those right-side elements to see which ones are bigger than `nums[i]`, and use the best one to build `dp[i]`

```python title=brute-force/recursion
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        memo = {}
        def dfs(i, j):
            if i == len(nums):
                return 0
            if (i,j) in memo:
                return memo[(i,j)]
            LIS = dfs(i+1,j)
            if j == -1 or nums[j] < nums[i]:
                LIS = max(LIS,dfs(i+1,i)+1)
            memo[(i,j)] = LIS
            return memo[(i,j)]
        return dfs(0,-1)
```

```python title=bottom-up
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        dp = [1] * len(nums)
        for i in range(len(nums)-1,-1,-1):
            for j in range(i+1, len(nums)):
                if nums[i] < nums[j]:
                    dp[i] = max(dp[i], 1+dp[j])
        return max(dp)
```
