## Problem

An **ugly number** is a _positive_ integer which does not have a prime factor other than 2, 3, and 5.

Given an integer `n`, return `true` _if_ `n` _is an **ugly number**_.

---
# Example 1

**Input:** `int n = 6;`

**Output:** true

**Explanation:** 6 = 2 × 3


---
# Solution

>[!important] Intuition
>- Every number is built from prime building blocks
>- From Claude: The core intuition is that **every number is built from prime “building blocks,” and each number has exactly one set of them.** (Mathematicians call this the Fundamental Theorem of Arithmetic.)
>- **Removing one kind of brick doesn’t change the others.** Dividing out a 2 can’t create or destroy a 7. So whatever forbidden primes were there at the start are still there at the end

```c++
class Solution {
public:
    bool isUgly(int n) {
        vector<int> v = {2,3,5};
        if (n<=0){
            return false;
        }
        for (int i = 0; i < v.size(); i++){
            while (n%v[i]==0){
                n/=v[i];
            }
        }
        return n == 1;
    }
};
```

---
# Time & Space Complexity

**Time Complexity:** $O(n)$
**Space Complexity:** $O(1)$
