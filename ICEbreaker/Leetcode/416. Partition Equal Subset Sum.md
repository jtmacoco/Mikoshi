## Problem

Given an integer array `nums`, return `true` _if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or_ `false` _otherwise_.

---
# Example 1

**Input:** `nums = [1,5,11,5]`

**Output:** `true`

**Explanation:** `The array can be partitioned as [1, 5, 5] and [11]`


---
# Solution

>[!important] Intuition
>- Brute Force: do float math since in case the sum doesn't evenly divide will have decimal which isn't possible to sum up to with `int`s
>- Top-Down: Create a set of all possible sums achievable using only the elements we've processed so far
>- Any sum reachable from index `i` onward is either (a) a sum reachable using elements from `i+1` onward, with `nums[i]` added in, or (b) a sum reachable using elements from `i+1` onward, without touching `nums[i]` at all. That's the include/exclude choice, expressed set-wise instead of boolean-wise.

```python title=brute-force
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        target = sum(nums)/2
        def dfs(i,total):
            if total == target:
                return True
            if total > target: return False
            if i >= len(nums): return False
            return (dfs(i+1,total+nums[i]) or dfs(i+1,total))
        res = dfs(0,0)
        return res
```


```python title=top-down
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        target = sum(nums)/2
        memo = {}
        def dfs(i,total):
            if total == target:
                return True
            if total > target: return False
            if i >= len(nums): return False
            if (i,total) in memo:
                return memo[(i,total)]
            memo[(i,total)] = (dfs(i+1,total+nums[i]) or dfs(i+1,total))
            return memo[(i,total)]
        res = dfs(0,0)
        return res
```

```python title=bottom-up
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        if sum(nums)%2!=0:
            return False
        dp = set()
        dp.add(0)
        target = sum(nums)/2
        for i in range(len(nums)-1,-1,-1):
            nxtDP = set()
            for t in dp:
                nxtDP.add(t+nums[i])
                nxtDP.add(t)
                if target in nxtDP: return True#speeds it up
            dp = nxtDP
        return target in dp
```

**Time Complexity:** $O(n*target)$
**Space Complexity:** $O(target)$
