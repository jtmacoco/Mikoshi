## Problem

You are given an array of digits called `digits`. Your task is to determine the number of **distinct** three-digit even numbers that can be formed using these digits.

**Note**: Each _copy_ of a digit can only be used **once per number**, and there may **not** be leading zeros.

---
# Example 1

**Input:** `digits = [1,2,3,4]`

**Output:** 12

**Explanation:** The 12 distinct 3-digit even numbers that can be formed are 124, 132, 134, 142, 214, 234, 312, 314, 324, 342, 412, and 432. Note that 222 cannot be formed because there is only 1 copy of the digit 2.


---
# Solution

>[!important] Intuition
> Even numbers and use standard backtracking

```python
class Solution:
    def totalNumbers(self, digits: List[int]) -> int:
        res = set()
        def backTrack(cur,visited):
            if len(cur) > 3 or (cur and cur[0] == 0): 
                return
            if len(cur) == 3 and cur[-1]%2==0:
                res.add(tuple(cur))
                return
            for j in range(0,len(digits)):
                if j in visited: 
                    continue
                visited.add(j)
                cur.append(digits[j])
                backTrack(cur,visited)
                visited.remove(j)
                cur.pop()
        backTrack([],set())
        return len(res)
```

---
# Time & Space Complexity

**Time Complexity:** $O(n!)$
**Space Complexity:** $O(1)$ Doesn't count space of returned set
