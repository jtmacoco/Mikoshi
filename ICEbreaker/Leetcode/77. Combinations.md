## Problem

Given two integers `n` and `k`, return _all possible combinations of_ `k` _numbers chosen from the range_ `[1, n]`.

You may return the answer in **any order**.

---
# Example 1

**Input:** `n = 4, k = 2`

**Output:** `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

**Explanation:** There are 4 choose 2 = 6 total combinations. Note that combinations are unordered, i.e., [1,2] and [2,1] are considered to be the same combination.


---
# Solution

>[!important] Intuition
> Be careful with duplicates

```python
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res = []
        def backTrack(i,cur,visited):
            if len(cur) == k:
                res.append(cur[::])
                return
            if i > n:
                return
            for num in range(i,n+1):
                if num in visited:
                    return
                cur.append(num)
                visited.add(num)
                backTrack(i+1,cur,visited)
                cur.pop()
                visited.remove(num)
        backTrack(1,[],set())
        return res
```

```python title=optimal
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res = []
        def backtrack(start, cur):
            if len(cur) == k:
                res.append(cur[:])
                return
            # prune: not enough numbers left from `num` to `n` to fill remaining slots
            need = k - len(cur)
            for num in range(start, n - need + 2):
                cur.append(num)
                backtrack(num + 1, cur)
                cur.pop()
        backtrack(1, [])
        return res
```
