## Problem


---
# Example 1

**Input:** `nums = [1, 4, 3, 3, 2]`

**Output:** 2

**Explanation:**

```python
The strictly increasing subarrays of `nums` are `[1]`, `[2]`, `[3]`, `[3]`, `[4]`, and `[1,4]`.

The strictly decreasing subarrays of `nums` are `[1]`, `[2]`, `[3]`, `[3]`, `[4]`, `[3,2]`, and `[4,3]`.

Hence, we return `2`.
```

---
# Solution

>[!important] Intuition
>- Use two vars inc and dec to keep track of increasing and decreasing arrays


```python
class Solution:
    def longestMonotonicSubarray(self, nums: List[int]) -> int:
        res = 1
        inc = 1
        dec = 1
        for i in range(1,len(nums)):
            if nums[i-1] > nums[i]:
                inc+=1
                dec = 1
            elif nums[i-1] < nums[i]:
                dec+=1
                inc = 1
            else:
                dec=1
                inc=1
            res = max(res,dec,inc)
        return res
```
