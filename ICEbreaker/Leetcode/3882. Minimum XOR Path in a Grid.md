## Problem

You are given a 2D integer array `grid` of size `m * n`.

You start at the **top-left** cell `(0, 0)` and want to reach the **bottom-right** cell `(m - 1, n - 1)`.

At each step, you **may** move either **right or down**.

The **cost** of a path is defined as the **bitwise XOR** of all the values in the cells along that path, **including** the start and end cells.

Return the **minimum** possible XOR value among all valid paths from `(0, 0)` to `(m - 1, n - 1)`.

---
# Example 1

**Input:** `grid = [[1,2],[3,4]]`

**Output:** 6

**Explanation:**
```
There are two valid paths:

- `(0, 0) → (0, 1) → (1, 1)` with XOR: `1 XOR 2 XOR 4 = 7`
- `(0, 0) → (1, 0) → (1, 1)` with XOR: `1 XOR 3 XOR 4 = 6`

The minimum XOR value among all valid paths is 6.
```

---
# Solution

>[!important] Intuition
>- Use default dict to maintain track of every path take up to a specific (row,col)
>- Keep track of all xor values basically

```python
class Solution:
    def minCost(self, grid: list[list[int]]) -> int:
        res = [float('inf')]
        seen = defaultdict(set)
        seen[(0,0)].add(grid[0][0])
        total = grid[0][0]
        def dfs(row,col,seen,total):
            if row == len(grid)-1 and col == len(grid[0])-1:
                res[0] = min(res[0],min(seen[(row,col)]))
                return
            dirs = [(0,1),(1,0)]
            for dr, dc in dirs:
                nr = dr+row
                nc = dc+col
                if(0<=nr<len(grid) and 0<=nc<len(grid[0])) :
                    val = total^grid[nr][nc]
                    if val not in seen[(nr,nc)]:
                        seen[(nr,nc)].add(val)
                        dfs(nr,nc,seen,total^grid[nr][nc])
                
        dfs(0,0,seen,total)
        return res[0]

```

```python title=dp
class Solution:
    def minCost(self, grid: list[list[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        dp = [[set() for _ in range(len(grid[0]))] for _ in range(len(grid))]
        dp[0][0].add(grid[0][0])
        for row in range(len(grid)):
            for col in range(len(grid[0])):
                if row == 0 and col == 0:
                    continue
                val = grid[row][col]
                if col > 0:
                    for x in dp[row][col-1]:
                        dp[row][col].add(x^val)
                if row >0: 
                    for x in dp[row-1][col]:
                        dp[row][col].add(x^val)

        return min(dp[rows-1][cols-1])
```
