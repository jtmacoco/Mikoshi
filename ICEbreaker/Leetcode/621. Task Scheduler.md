## Problem

You are given an array of CPU `tasks`, each labeled with a letter from A to Z, and a number `n`. Each CPU interval can be idle or allow the completion of one task. Tasks can be completed in any order, but there's a constraint: there has to be a gap of **at least** `n` intervals between two tasks with the same label.

Return the **minimum** number of CPU intervals required to complete all tasks.

---
# Example 1

**Input:** 
`tasks = ["A","A","A","B","B","B"], n = 2`

**Output:** 8

**Explanation:**
```
**Explanation:** A possible sequence is: A -> B -> idle -> A -> B -> idle -> A -> B.

After completing task A, you must wait two intervals before doing A again. The same applies to task B. In the 3rd interval, neither A nor B can be done, so you idle. By the 4th interval, you can do A again as 2 intervals have passed.
```

---
# Solution

>[!important] Intuition
>Greedily run the available task with the highest remaining count. Most freq task create the most cooldown gaps, so spending them early lets other tasks fill those gaps
>- **max-heap**: counts of task available now
>- **Queue**: used for tasks on cooldown. Ready times are added in increasing order FIFO
>- **Each tick**: pop the top of the heap decrement it and if it's still nonzero enqueue it. Then if front of queue is ready push it back onto the heap. Empty heap means idle tick which is why must continue until queue is empty

```python
class Solution:
    def leastInterval(self, tasks: list[str], n: int) -> int:
        freq = Counter(tasks)
        max_heap = [-v for k,v in freq.items()]
        heapify(max_heap)
        q = deque()
        time = 0
        while max_heap or q:
            time+=1
            if max_heap:
                cnt = 1+heappop(max_heap)
                if cnt:
                    q.append((cnt,time+n))
            if q and q[0][1] == time:
                c,_ = q.popleft()
                heappush(max_heap,c)

        return time
```

**Time Complexity:** $O(n)$
**Space Complexity:** $O(n)$
