## Problem

Given an integer array `nums`, return _an array_ `answer` _such that_ `answer[i]` _is equal to the product of all the elements of_ `nums` _except_ `nums[i]`. The product of any prefix or suffix of `nums` is **guaranteed** to fit in a **32-bit** integer. You must write an algorithm that runs in `O(n)` time and without using the division operation.

---
# Example 1

**Input:** `nums=[1,2,3,4]`
**Output:** `nums=[24,12,8,6]`

---
# Solution

>[!important] Intuition
> Use a hashtable or 2 var's to keep track of multiplying prev order and post order

Init:`prev = [1, 1, 1, 1]`
Init:`post = [1, 1, 1, 1]`


`prev = [1, 1, 2, 6]`

`post = [24, 12, 4, 1]`

Element-wise:

| i   | prev | post | result |
| --- | ---: | ---: | -----: |
| 0   |    1 |   24 |     24 |
| 1   |    1 |   12 |     12 |
| 2   |    2 |    4 |      8 |
| 3   |    6 |    1 |      6 |

`result[i] = prev[i] * post[i]`


```python title=array-based
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        prev = [1]*len(nums)
        post = [1]*len(nums)
        res = []
        for i in range(1,len(nums)):
            prev[i]=nums[i-1]*prev[i-1]
        for i in range(len(nums)-2,-1,-1):
            post[i]=nums[i+1]*post[i+1]
        for i in range(len(nums)):
            res.append(post[i]*prev[i])
        return res
```

```python title=space-o(1)
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        prev = 1
        post = 1
        res = [1]*len(nums)
        for i in range(len(nums)):
            res[i]=prev
            prev*=nums[i]
        for i in range(len(nums)-1,-1,-1):
            res[i]*=post
            post*=nums[i]

        return res
```

```cpp title=c++-solution
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int post = 1;
        int prev = 1;
        vector<int> res;
        res.resize(nums.size());
        for(int i = 0; i < nums.size(); i++){
            res[i]=prev;
            prev*=nums[i];
        }
        for(int i = nums.size()-1; i >= 0; i--){
            res[i]*=post;
            post*=nums[i];
        }
        return res;
    }
};
```
