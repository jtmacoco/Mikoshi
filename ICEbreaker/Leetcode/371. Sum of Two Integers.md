## Problem

Given two integers `a` and `b`, return _the sum of the two integers without using the operators_ `+` _and_ `-`.

---
# Example 1

**Input:** `a = 1, b = 2`

**Output:** 3

---
# Solution

>[!important] Intuition
>- Use XOR with AND logic
>- Similar to how we did in architecture class sjsu

```c++
class Solution {
public:
    int getSum(int a, int b) {
        while (b != 0){
            int tmp = (a&b)<<1;
            a ^= b;
            b = tmp;
        }
        return a;
    }
};
```
