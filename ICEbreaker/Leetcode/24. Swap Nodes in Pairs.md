## Problem

Given a linked list, swap every two adjacent nodes and return its head. You must solve the problem without modifying the values in the list's nodes (i.e., only nodes themselves may be changed.)

---
# Example 1

**Input:** `head = [1,2,3,4]`

**Output:** `[2,1,4,3]`

# Solution

>[!important] Intuition
> Dummy is a fixed node used for return
> Prev is the pointer that stitches each newly swapped pair onto the previous part of the list.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        cur = head
        prev = ListNode(next=cur)
        dummy = prev
        while cur and cur.next:
            tmp = cur.next.next
            snd = cur.next

            snd.next = cur
            cur.next = tmp
            prev.next = snd

            prev = cur
            cur = tmp

        
        return dummy.next

```
