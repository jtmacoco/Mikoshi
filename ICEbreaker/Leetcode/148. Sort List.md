## Problem

Given the `head` of a linked list, return _the list after sorting it in **ascending order**_.

---
# Example 1

**Input:** `head = [4,2,1,3]`

**Output:** `[1,2,3,4]`

---
# Solution

>[!important] Intuition
> - Use a list to store values then sort
> - Can use fast and slow ptr technique I think try again later


```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def sortList(self, head: ListNode | None) -> ListNode | None:
        cur = head
        dmy = []
        while cur:
            dmy.append(cur.val)
            cur = cur.next
        dmy.sort()
        d = ListNode()
        res = d
        for val in dmy:
            node = ListNode(val=val)
            d.next = node
            d = d.next

        return res.next
```

---
# Time & Space Complexity

**Time Complexity:** $O(n\log(n))$
**Space Complexity:** $O(n)$
