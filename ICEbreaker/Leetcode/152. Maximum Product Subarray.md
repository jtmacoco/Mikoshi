## Problem

Given an integer array `nums`, find a that has the largest product, and return _the product_.

The test cases are generated so that the answer will fit in a **32-bit** integer.

**Note** that the product of an array with a single element is the value of that element.

---
# Example 1

**Input:** `nums = [2,3,-2,4]`

**Output:** 6

**Explanation:** `[2,3] has the largest product 6.`


---
# Solution

>[!important] Intuition
> - Keep track of the max and min of the sub-array since multiplying by negatives can give a large positive value

```python title=brute-force
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        res = float('-inf')
        for i in range(len(nums)):
            total = nums[i]
            for j in range(i+1,len(nums)):
                res = max(res,total)
                total*=nums[j]
            res = max(res,total)
        res = max(res,total)
        return res if res!= float('-inf') else 0

```

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        res = max(nums)
        curMin, curMax = 1,1
        for i in range(len(nums)):
            tmp = curMax * nums[i]# used since curMax will overwrite
            curMax = max(curMax*nums[i],nums[i]*curMin,nums[i])
            curMin = min(tmp, nums[i] * curMin, nums[i])
            res = max(res,curMax)
        return res
```

all positive = `[1, 2, 3]` 
- This is easy since we can do a greedy approach
all negatives = `[-1, -2, -3]` 
- Difficult since odd number of negatives equals positive
- So for each `nums[i]`  we keep track of the max and min so for example the max of `-1 * -2 = 2` but the min is `-2` 
- The next check we also do at every index is to see which provides the larger value `curMax * nums[i]` or `curMin * nums[i]` it is this `curMin` which helps deal with the negative multiplication
- Tricky problem lol
- this similar to [[152. Maximum Product Subarray]]  the house robber problem in the sense that we multiple by the max value or min value which then leads to the max multiplication?
