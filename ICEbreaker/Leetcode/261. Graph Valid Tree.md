## Problem

Given `n` nodes labeled from `0` to `n - 1` and a list of **undirected** edges (each edge is a pair of nodes), write a function to check whether these edges make up a valid tree

---
# Example 1

**Input:**  `n = 5, edges = [[0,1],[0,2],[0,3],[1,4]]`

**Output:** `True`

---
# Solution

>[!important] Intuition
> Build bi-directional adj tree (undirected graph)
> Use visited set to keep track of all nodes visited
> Use a parent arg to see if child is the parent if so skip, since we can allow for parent and child to point to one another (NOT A CYCLE) otherwise it is a cycle

```python
class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        visited = set()
        adj = defaultdict(list)
        for i, j in edges:
            adj[i].append(j)
            adj[j].append(i)

        def dfs(val,parent):
            if val in visited:
                return False
            visited.add(val)
            for n in adj[val]:
                if parent == n:
                    continue
                if not dfs(n,val):
                    return False
            return True
        res = dfs(0,-1)
        return res if len(visited) == n else False
```
