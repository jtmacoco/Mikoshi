## Problem

Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements.

**Note** that you must do this in-place without making a copy of the array.

---
# Example 1

**Input:**  `nums = [0,1,0,3,12]`

**Output:** `[1,3,12,0,0]`

---
# Solution

>[!important] Intuition
> - Use two pointers to keep track of where you are in nums then decrement or increment depending if landed on a $0$
> - Optimal solution: for every non zero swap it with `nums[i]` and vice versa this


```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        if len(nums) < 2:
            return
        left = 0
        right = len(nums)-1
        while left <= right:
            if nums[left] == 0:
                nums.append(0)
                del(nums[left])
                right-=1
            else:
                left+=1
        """
        Do not return anything, modify nums in-place instead.
        """
  
```

```python title=optimal
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        last_non_z = 0
        for i in range(len(nums)):
            if nums[i] != 0:
                nums[last_non_z], nums[i] = nums[i], nums[last_non_z]
                last_non_z += 1
        """
        Do not return anything, modify nums in-place instead.
        """
```
