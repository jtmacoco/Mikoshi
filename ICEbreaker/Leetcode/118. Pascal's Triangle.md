## Problem

You are given an integer `numRows`.

Return the first `numRows` of **Pascal's triangle**.

In **Pascal's triangle**, each number is the sum of the two numbers directly above it and the first and last number on each row must be equal to 1, as shown below:

**Output:** ` [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

# Solution

>[!important] Intuition
>- I hate this problem due to missing it in AP cs in high school
>- Basically use an array and perform the simple addition skipping the ends since they will always be 1

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = [[1]]
        if numRows == 1:
            return res
        for i in range(1,numRows):
            prev = res[i-1]
            res.append([1])
            for j in range(1,i):
                val = prev[j-1] + prev[j]
                res[i].append(val)
            res[i].append(1)
        return res

```
