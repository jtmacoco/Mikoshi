## Problem

Given `n` pairs of parentheses, write a function to _generate all combinations of well-formed parentheses_.

---
# Example 1

**Input:** `n = 3`

**Output:**  `["((()))","(()())","(())()","()(())","()()()"]`

---
# Solution

>[!important] Intuition
>- Can't use string strings are immutable so it would be like creating a new str obj everyttime manipulated it
>- Use a list to keep track of parentheses 
>- Make sure closed < opened < n  this is basically the core intuition

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        res = []
        def backTrack(opened,closed,cur):
            if opened > n or closed > n:
                return
            if opened == closed == n:
                res.append("".join(cur))
                return
            if opened < n:
                cur.append("(")
                backTrack(opened+1,closed,cur)
                cur.pop()
            if closed < opened:
                cur.append(")")
                backTrack(opened,closed+1,cur)
                cur.pop()
        backTrack(0,0,[])
        return res
```
