## Problem

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

---
# Example 1

**Input:** `s = "anagram", t = "nagaram"`

**Output:** `true`


---
# Solution

>[!important] Intuition
> Use a hash map to keep track of the characters in each string

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        freq_a = [0]*26
        freq_t = [0]*26
        if len(s)!=len(t):
            return False
        for i in range(len(s)):
            s_ch = s[i]
            t_ch = t[i]
            freq_a[ord('a')-ord(s_ch)]+=1
            freq_t[ord('a')-ord(t_ch)]+=1

        return freq_a==freq_t
```

---
# Time & Space Complexity

**Time Complexity:** $O(n)$
**Space Complexity:** $O(1)$
