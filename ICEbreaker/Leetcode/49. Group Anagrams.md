**Description**: Given an array of strings `strs`, group the together. You can return the answer in **any order**.

---
# Example 1

**Input:** strs = `["eat","tea","tan","ate","nat","bat"]`

**Output:** `[["bat"],["nat","tan"],["ate","eat","tea"]]`

**Explanation:**

- There is no string in strs that can be rearranged to form `"bat"`.
- The strings `"nat"` and `"tan"` are anagrams as they can be rearranged to form each other.
- The strings `"ate"`, `"eat"`, and `"tea"` are anagrams as they can be rearranged to form each other.

---

# Solution

>[!important] Intuition
>Use a hash table to keep track of char's in a word, then use that as the index for a dict

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        res = defaultdict(list)
        for i in range(len(strs)):
            freq = [0]*26
            for ch in strs[i]:
                freq[ord(ch)-ord('a')]+=1
            res[tuple(freq)].append(strs[i])
        return list(res.values())
```

---
# Time & Space Complexity 

**Time Complexity:**  $O(n*k)$ where n is length of nums and k is the avg num characters in word
**Space Complexity**: $O(n*k)$ where n is length of nums and k is the avg num characters in word
