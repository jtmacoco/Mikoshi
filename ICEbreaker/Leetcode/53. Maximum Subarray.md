## Problem

Given an integer array `nums`, find the with the largest sum, and return _its sum_.

---
# Example 1

**Input:** nums = `[-2,1,-3,4,-1,2,1,-5,4]`
**Output:** 6
**Explanation:** The subarray `[4,-1,2,1]` has the largest sum 6.

---
# Solution

>[!important] Intuition
> Keep track of the current sum disregarding negative values so if it's negative reset current sum to 0.  Then keep a global max of the current sum

| Index |  0  |  1  |  2  |  3  |  4  |  5  |  6  |  7  |  8  |
| ----: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| Value | -2  |  1  | -3  |  4  | -1  |  2  |  1  | -5  |  4  |

| i   | cur_sum | max |
| --- | ------- | --- |
| 0   | -2      | -2  |
| 1   | 1       | 1   |
| 2   | -2      | 1   |
| 3   | 4       | 4   |
| 4   | 3       | 4   |
| 5   | 5       | 5   |
| 6   | 6       | 6   |
| 7   | 1       | 6   |
| 8   | 5       | 6   |

```python title=Kandes-Algorithm
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        mx = nums[0]
        cur_mx = 0
        for i in range(len(nums)):
            if cur_mx < 0:
                cur_mx = 0
            cur_mx += nums[i]
            mx = max(mx,cur_mx)
        return mx
            
```


```python title=brute-force
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        res = nums[0]
        for i in range(len(nums)):
            cur_sum = 0
            for j in range(i,len(nums)):
                cur_sum+=nums[j]
                res = max(res,cur_sum)
        return res
```
