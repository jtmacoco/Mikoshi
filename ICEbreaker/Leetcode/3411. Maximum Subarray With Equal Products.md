## Problem

You are given an array of **positive** integers `nums`.

An array `arr` is called **product equivalent** if `prod(arr) == lcm(arr) * gcd(arr)`, where:

- `prod(arr)` is the product of all elements of `arr`.
- `gcd(arr)` is the GCD of all elements of `arr`.
- `lcm(arr)` is the LCM of all elements of `arr`.

Return the length of the **longest** **product equivalent** subarray of `nums`.

---
# Example 1

**Input:** `[1,2,1,2,1,1,1]`

**Output:** 5

**Explanation:**

```
The longest product equivalent subarray is `[1, 2, 1, 1, 1]`, where `prod([1, 2, 1, 1, 1]) = 2`, `gcd([1, 2, 1, 1, 1]) = 1`, and `lcm([1, 2, 1, 1, 1]) = 2`.
```

---
# Solution

>[!important] Intuition
>- Brute force it but cap it based on gcd and lcm max out via constraints

```python
class Solution:
    def maxLength(self, nums: List[int]) -> int:
        mx = math.lcm(*range(1, 11))*10
        res = 0
        for i in range(len(nums)):
            total = nums[i]
            for j in range(i+1,len(nums)):
                gcd = math.gcd(*nums[i:j+1])
                lcm = math.lcm(*nums[i:j+1])
                prod = gcd*lcm
                total*=nums[j]
                if total == prod:
                    res = max(res,j-i+1)
                if total > mx:
                    break
        return res

```

---
# Time & Space Complexity

**Time Complexity:** $O(n^3\log(m))$ where $m$ is the largest value in nums
**Space Complexity:** $O(n^3\log(m))$

$n^3$ comes from the fact that are re-computing the gcd and lcm every time
