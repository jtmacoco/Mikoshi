## Problem

Given a **non-empty** array of integers `nums`, every element appears _twice_ except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

---
# Example 1

**Input:** `nums = [2,2,1]`

**Output:** `1`

---
# Solution

>[!important] Intuition
> Can do a normal loop and hash map.
> More efficient to use XOR since any value XOR with itself is just 0. This property will remove all duplicates leaving the single number

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int res = 0;
        for(int i = 0; i < nums.size(); i++){
            res ^= nums[i];
        }
        return res;
    }
};
```

---
# Time & Space Complexity

**Time Complexity:** $O(n)$
**Space Complexity:** $O(1)$
