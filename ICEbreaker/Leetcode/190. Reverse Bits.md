## Problem

Reverse bits of a given 32 bits signed integer.

---
# Example 1

**Input:** 43261596

**Output:** 964176192

**Explanation:**

| Integer   | Binary                           |
| --------- | -------------------------------- |
| 43261596  | 00000010100101000001111010011100 |
| 964176192 | 00111001011110000010100101000000 |

---
# Solution

>[!important] Intuition
> You pop bits off the right end of `n` one at a time and push each onto the right end of `res`, so the first bit you take out ends up furthest left, which reverses the order, just like reversing digits of a number with `% 10` and `* 10`

```cpp
class Solution {
public:
    int reverseBits(int n) {
        int res = 0;
        cout<<n<<endl;
        for (int i = 0; i < 32; i++){
            res <<= 1;
            res |= (n&1);
            cout<<res<<endl;
            n>>=1;
        }
        return res;
    }
};
```
