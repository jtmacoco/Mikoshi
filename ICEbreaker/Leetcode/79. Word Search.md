## Problem

Given an `m x n` grid of characters `board` and a string `word`, return `true` _if_ `word` _exists in the grid_.

The word can be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

---
# Example 1

![[79. Word Search-20260927151921393.png]]

**Input:** `board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"`

**Output:** `true`

---
# Solution

>[!important] Intuition
> - Use dfs to check all of the squares
> - Need to remove from seen after dfs calls too allow us to go back to prior states and try their locations again in case missed one

```python
class Solution(object):
    def exist(self, board, word):
        ROWS = len(board)
        COLS = len(board[0])
        def dfs(row,col,index, visited):
            if (row < 0 or row >= ROWS or
                col < 0 or col >= COLS or
                (row,col) in visited or 
                board[row][col] != word[index]
            ):
                return False
            if index == len(word)-1:
                print(word[index])
                return True
            visited.add((row,col))
            found = (dfs(row+1,col,index+1,visited) or
                    dfs(row-1,col,index+1,visited) or
                    dfs(row,col+1,index+1,visited) or
                    dfs(row,col-1,index+1,visited)
            )
            visited.remove((row,col))
            return found
        for row in range(ROWS):
            for col in range(COLS):
                ch = board[row][col]
                if ch == word[0] and dfs(row,col,0,set()):
                    return True
        return False
        """
        :type board: List[List[str]]
        :type word: str
        :rtype: bool
        """
```

# Time & Space Complexity

**Time Complexity:** $O( M*M*4^k)$  the $4$ comes from the 4 separate branches up, down, left, right, and $k$ the length of the word
**Space Complexity:**$O(L)$ where $L$ is the length of the word
