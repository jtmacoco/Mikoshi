## Problem

Given a positive integer `n`, write a function that returns the number of in its binary representation (also known as the [Hamming weight](http://en.wikipedia.org/wiki/Hamming_weight)).

---
# Example 1

**Input:**  `n = 11`

**Output:** `3`

**Explanation:**

The input binary string 1011 has a total of three set bits


---
# Solution

>[!important] Intuition
> Use [[Kernighan Trick]]

```python
class Solution:
    def hammingWeight(self, n: int) -> int:
        res = 0
        while n:
            n &= n-1
            res+=1
        return res
```

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int res = 0;
        while(n > 0){
            n &= n-1;
            res +=1;
        }
        return res;
    }
};
```

---
# Time & Space Complexity

**Time Complexity:** $O(n)$ where $n$ is the number of set bits
**Space Complexity:** $O(1)$
