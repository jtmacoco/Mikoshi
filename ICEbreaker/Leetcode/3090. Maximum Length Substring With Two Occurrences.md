## Problem

Given a string `s`, return the **maximum** length of a  such that it contains _at most two occurrences_ of each character.

---
# Example 1

**Input:** "bcbbbcba"

**Output:** 4

**Explanation:** The following substring has a length of 4 and contains at most two occurrences of each character: `"bcbbbcba"`.


---
# Solution

>[!important] Intuition
> Use sliding window to check if count is greater than 2


```python
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        res = 0
        left = 0
        count = {}
        for right in range(len(s)):
            val = s[right]
            count[val] = count.get(val,0)+1
            while count[val] > 2:
                count[s[left]]-=1
                left+=1
            res = max(res,right-left+1)
        return res
```

---
# Time & Space Complexity

**Time Complexity:** $O(n)$
**Space Complexity:** $O(n)$
