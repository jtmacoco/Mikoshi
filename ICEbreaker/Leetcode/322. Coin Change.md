## Problem

You are given an integer array `coins` representing coins of different denominations and an integer `amount` representing a total amount of money.

Return _the fewest number of coins that you need to make up that amount_. If that amount of money cannot be made up by any combination of the coins, return `-1`.

You may assume that you have an infinite number of each kind of coin

---
# Example 1

**Input:** `coins = [1,2,5], amount = 11`

**Output:** 3

**Explanation:** 11 = 5 + 5 + 1


---
# Solution

>[!important] Intuition
> Use a decision tree to help with recursive solution
>  Try to look at it instead of adding up, subtract down to 0
>  Then Bottom Up approach is a bit odd but same process, just make sure to init DP correctly and set up the nested loops

```python title=brute-force
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        def dfs(i,total, count):
            if total > amount:
                return  float('inf')
            if total == amount:
                return count
            mini = float('inf')
            for j in range(i,len(coins)):
                mini = min(mini,dfs(j,total+coins[j],count+1))
            return mini
        res = dfs(0,0,0)
        return res if res != float('inf') else -1
```

```python title=memo
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        memo = {}
        def dfs(total):
            if total < 0:
                return  float('inf')
            if total == 0:
                return 0
            if total in memo:
                return memo[total]
            mini = float('inf')
            for j in range(len(coins)):
                mini = min(mini,dfs(total-coins[j])+1)
            memo[total] = mini
            return memo[total]
        res = dfs(amount)
        return res if res != float('inf') else -1
```

```python title=bottom-up
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [float('inf')] * (amount+1)
        dp[0] = 0
        for i in range(1,amount+1):
            mini = float('inf')
            for j in range(len(coins)):
                if i-coins[j] >= 0:
                    mini = min(mini,dp[i-coins[j]]+1)
            dp[i] = mini
        return dp[-1] if dp[-1] != float('inf') else -1
```

# Time & Space Complexity

**Time Complexity:** $O(n*m)$ where `n = amount` and `m = len(coins)`
**Space Complexity:** $O(n)$
