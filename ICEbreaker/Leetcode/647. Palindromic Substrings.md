## Problem

Given a string `s`, return _the number of **palindromic substrings** in it_.
A string is a **palindrome** when it reads the same backward as forward.
A **substring** is a contiguous sequence of characters within the string.

---
# Example 1

**Input:** `s = "abc"`

**Output:** 3

**Explanation:** Three palindromic strings: "a", "b", "c".


---
# Solution

>[!important] Intuition
> Build the palindrome around a character rather than starting from the `start` and `end` use the current character as the middle of a palindrome. 


```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        res = 0
        for i in range(len(s)):
            l = i
            r = i
            while r < len(s) and l >= 0 and s[l] == s[r]:
                l-=1
                r+=1
                res+=1
            l = i
            r = i+1
            while r < len(s) and l >= 0 and s[l] == s[r]:
                l-=1
                r+=1
                res+=1
        return res

```

### Dynamic approach 

Input: `aabaaca`

| 0   | 1   | 2   | 3   | 4   | 5   | 6   |
| --- | --- | --- | --- | --- | --- | --- |
| a   | a   | b   | a   | a   | c   | a   |

| indexes |     | 0   | 1   | 2   | 3   | 4   | 5   | 6   |
| ------- | --- | --- | --- | --- | --- | --- | --- | --- |
|         |     | a   | a   | b   | a   | a   | c   | a   |
| 0       | a   | 1   | 1   | 0   | 0   | 0   | 0   | 0   |
| 1       | a   |     | 1   | 0   | 1   | 0   | 0   | 0   |
| 2       | b   |     |     | 1   | 0   | 0   | 0   | 0   |
| 3       | a   |     |     |     | 1   | 0   | 0   | 0   |
| 4       | a   |     |     |     |     | 1   | 0   | 0   |
| 5       | c   |     |     |     |     |     | 1   | 0   |
| 6       | a   |     |     |     |     |     |     | 1   |
|         |     |     |     |     |     |     |     |     |
```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        dp = [[0 for _ in range(len(s))] for _ in range(len(s))]
        res = 0
        for i in range(len(s)):
            dp[i][i] = 1
            res+=1
        for col in range(1,len(s)):
            for row in range(0,col):
                if row == col-1 and s[col] == s[row]:
                    dp[row][col] = 1
                    res+=1
                if dp[row+1][col-1] == 1 and s[col] == s[row]:
                    dp[row][col] = 1
                    res+=1
        return res

```

>[!important] DP intuition
> A substring is a palindrome if its two outer characters match and the inner substring between them is already known (from the DP table) to be a palindrome

- **State:** `dp[i][j]` = True if `s[i:j+1]` (the substring from index `i` to `j`) is a palindrome
- **Base case:** every single character is a palindrome → `dp[i][i] = True`
- **Recurrence:** `s[i:j+1]` is a palindrome if:
    - the outer characters match (`s[i] == s[j]`), **and**
    - the inner substring is also a palindrome — either `dp[i+1][j-1]` is True, or there's no real inner substring to check (length ≤ 2, i.e. `j - i < 2`)
- **Why DP works here:** the palindrome-check for a longer substring depends only on a _smaller, already-computed_ substring — so instead of re-checking the middle every time, you just look it up
- **Fill order matters:** you must compute shorter substrings before longer ones, since `dp[i][j]` depends on `dp[i+1][j-1]` (a strictly smaller range) — this is why you loop by increasing length (or column-by-column, row ≤ column)
- **Result:** count/store `True` entries as you go, or scan the finished table depending on what the problem asks for (count, longest, etc.)
- **Cost:** O(n²) time and O(n²) space — since there are O(n²) substrings and each is checked in O(1) using the table
- **Trade-off to remember:** for _counting_ palindromic substrings specifically, an O(1)-space "expand around center" approach does the same job without the table — DP earns its space cost mainly when you need to _reuse_ the palindrome table repeatedly (e.g. in Palindrome Partitioning II)

>[!danger] Watch out for
>This DP solution has a worse space complexity since initializes a 2D DP array
