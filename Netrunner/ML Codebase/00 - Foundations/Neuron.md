## What is Neuron

- A neuron is like it's own function
- If using linear equation then can think of each neuron as having it's own linear equation
- Neurons and Weights both contribute to higher dimensionality. 

> Dimensionality comes from the total count of trainable numbers — weights _and_ biases together — not from "number of neurons" as its own separate thing. More neurons means more dimensions mainly _because_ more neurons means more weights and biases, not because the neuron count is itself an axis.
